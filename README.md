# Model Splitter — variantă gratuită

Aplicație pentru Android (APK) și Windows (EXE), construită automat și gratuit.

## Ce faci tu

1. Creează un cont gratuit pe GitHub.
2. Creează un repository **public**.
3. Încarcă toate fișierele din acest folder.
4. Mergi la Actions → Build Android APK and Windows EXE → Run workflow.
5. Descarcă fișierele din Artifacts.

## Ce primești

- APK pentru Android.
- Aplicație Windows gata de rulat.
- Totul este gratuit dacă repository-ul este public.

## Notă

Versiunea 1.0 taie modelul și exportă piesele. Pinii și socket-urile avansate urmează în versiunea următoare.
